# Hybrid Intrusion Detection System

A real-time network intrusion detection system using:

- Random Forest
- XGBoost
- Autoencoder

## Features

- Live packet capture
- Flow generation
- Hybrid detection engine
- Real-time dashboard
- Threat visualization
- Alert logging

## Tech Stack

- Python
- Flask
- Scapy
- TensorFlow
- XGBoost
- HTML/CSS/JavaScript

## Run

pip install -r requirements.txt

python -m backend.app
